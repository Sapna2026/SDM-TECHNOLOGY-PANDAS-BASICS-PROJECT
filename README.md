## 📌 Project Overview

This project is part of my **SDM TECHNOLOGY-PANDAS-BASIC PROJECT**. It focuses on developing practical data analysis skills using Python and the Pandas library.

The project includes 20 exercises with solutions and explanations, using realistic sample datasets to practice filtering, grouping, merging, and exploring structured data.

## 🎯 Objectives

- Understand and inspect datasets using Pandas.
- Filter records using conditions, dates, lists, and text searches.
- Group data to calculate counts, sums, averages, and other summaries.
- Merge related datasets using common keys.
- Create analysis-ready tables and calculate order values.
- Identify customers who do not have matching orders.

## 📚 Topics Covered

### 1. Data Inspection
- Exploring DataFrame structure and data types.
- Checking missing values.
- Reviewing numerical summaries.

### 2. Data Filtering
- Filtering delivered orders.
- Selecting orders by quantity.
- Combining multiple conditions.
- Filtering customers by city and segment.
- Searching product names.
- Filtering records by date range.

### 3. Data Grouping
- Counting orders by status.
- Calculating total quantities by product and customer.
- Finding average quantities.
- Counting customers by city.
- Calculating minimum and maximum prices by category.
- Summarizing orders by month.

### 4. Data Merging
- Combining orders with customer details.
- Adding product information and prices.
- Calculating order line values.
- Creating a complete order report.
- Calculating delivered order value by city.
- Identifying customers without orders using merge indicators.

## 🚀 How to Run

1. Download or clone this repository.
2. Install Python if it is not already installed.
3. Install the required libraries:

   ```bash
   pip install pandas jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the `.ipynb` file and run the cells sequentially.

You can also upload the notebook to [Google Colab](https://colab.research.google.com/) to run it in your browser.

## 💡 Key Learnings

Through this project, I practiced:

- Applying conditional filtering to real-world-style datasets.
- Using `groupby()`, `sum()`, `mean()`, `size()`, and `agg()`.
- Connecting datasets using Pandas `merge()`.
- Working with dates and text columns.
- Calculating order-level values and summarizing results.
- Checking missing values and unmatched records.
